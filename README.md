# Планирование закупок и продаж цветочной продукции на основе машинного обучения

**Тема выпускной квалификационной работы (планируемая):**
«Разработка информационной системы планирования процессов закупки и продажи цветочной продукции на основе методов машинного обучения для прогнозирования спроса»

Репозиторий — основа будущей дипломной работы. Сейчас в нём собраны результаты практических работ по курсу «Программная инженерия» (ТулГУ, ИПМКН). В этих работах для системы выполнены обследование и анализ осуществимости, сформулированы требования и ТЗ, построены функциональная и объектная модели и план проекта. Там же лежит первый прототип прогнозирования спроса и расчёта заказа. На этой базе дальше будет вестись разработка ВКР.

## Идея системы

Срезанные цветы — скоропортящийся товар: срок реализации у них 5–14 дней. Спрос при этом резко скачет перед 14 февраля, 8 марта, 1 сентября и Новым годом. Ошибка в закупке приводит либо к **списаниям** (у компании они доходили до 15–18 % закупочной стоимости), либо к **дефициту** в пиковые дни.

Система делает четыре вещи:

- ведёт **партионный учёт** со сроками реализации (принцип FEFO);
- строит **прогноз спроса** по товарам и торговым точкам на горизонт до 14 дней, с квантилями;
- формирует **рекомендуемый заказ поставщику** по модели «продавца газет» (newsvendor), с учётом остатков, сроков поставки, кратности упаковки и бюджета;
- рекомендует **уценку** партий, у которых истекает срок, и ведёт аналитику списаний.

| Подсистема | Назначение |
|---|---|
| НСИ | Номенклатура, поставщики, условия поставки, календарь праздников |
| Учёт запасов и партий | Приёмка (ТСД), партии со сроками, остатки, перемещения |
| Учёт продаж и заказов | Кассы и «1С:Розница», интернет-магазин, предзаказы |
| Прогнозирование спроса (ML) | Признаки, модели, квантили P50/P80/P95, контроль WAPE |
| Планирование закупок | Расчёт заказов, сценарии праздников, согласование, отправка |
| Сроки и уценка | Контроль «годен до», рекомендации по скидкам, списание |
| Аналитика | ABC/XYZ, оборачиваемость, доля списаний, точность прогноза |

## Подход к машинному обучению

- **Уровень прогноза:** товар (группа) × торговая точка × день, горизонт 14 дней.
- **Признаки:** лаги и скользящие средние продаж, день недели, число дней до праздника, сезонность, цена и акции, погода, признак дефицита (поправка на «цензурированный» спрос).
- **Базовые модели:** сезонная наивная, Хольт–Уинтерс, метод Кростона (для прерывистого спроса).
- **Основная модель:** глобальный градиентный бустинг (LightGBM) с квантильной функцией потерь.
- **Метрики:** WAPE и bias, отдельно по предпраздничным дням.
- **Решение о заказе:** целевой уровень обслуживания α = Cu / (Cu + Co), где Cu — упущенная маржа, Co — потери от списания.

Прототип: [`ml/baseline_forecast.py`](ml/baseline_forecast.py). Он работает на синтетических данных: сравнивает сезонную наивную модель с бустингом и считает заказ по newsvendor.

```bash
pip install -r requirements.txt
python ml/baseline_forecast.py
```

## Структура репозитория

```
reports/     отчёты по практическим работам (DOCX + PDF)
diagrams/    диаграммы: IDEF0, IDEF3, VORD, ER, UML, сетевой график, Гант
ml/          прототипы моделей машинного обучения
tools/       генератор отчётов (python-docx + MS Word) — исходники текста и диаграмм
```

Отчёты собираются генератором из `tools/report_generator` (`python build.py`). Ему нужны Windows, MS Word, Java 11+ и [`plantuml.jar`](https://github.com/plantuml/plantuml/releases), положенный рядом со скриптами. Данные титульного листа задаются в `config.py`.
