# Интеграция с внешними системами (В-1, И-1)

Полная спецификация — OpenAPI 3 по адресу `/api/docs`. Внешние системы передают ключ в заголовке `X-API-Key` (настройки `FLORAPLAN_SHOP_API_KEY`, `FLORAPLAN_ONEC_API_KEY`).

## Интернет-магазин

| Метод | Назначение |
|---|---|
| `GET /api/shop/stock` | остатки, доступные к продаже (без резервов и просроченных партий) |
| `GET /api/shop/prices` | цены |
| `POST /api/shop/orders` | заказ: резервирует товар, годный на дату доставки |
| `GET /api/shop/orders/{номер}` | статус заказа |

```bash
curl -X POST http://host/api/shop/orders -H "X-API-Key: shop-demo-key" -H "Content-Type: application/json" -d '{
  "id": "SITE-10050", "delivery_date": "2026-11-01", "customer_name": "Покупатель", "phone": "+70000000000",
  "allow_preorder": true, "lines": [{"barcode": "4601234500012", "qty": 15}]}'
```

Ответ: `{"order_id": 12, "status": "reserved", "status_name": "Зарезервирован", "created": true, "total": 2400.0}`. Повторная передача заказа с тем же номером не создаёт дубликат (`created: false`). Если товара не хватает: при `allow_preorder: true` заказ становится предзаказом (`preorder`), иначе — ответ 409 с полем `shortage` (запрошено и доступно по позициям). Статусы: `new`, `preorder`, `reserved`, `completed`, `cancelled`.

Если задан `FLORAPLAN_SHOP_WEBHOOK_URL`, каждые 15 минут система сама отправляет на этот адрес `POST` с `{"stock": …, "prices": …}`.

### Маркетплейсы и другие сайты (Р-4)

Новые каналы продаж подключаются без изменения программы: «Администрирование → Каналы продаж → Подключить канал». Для канала задаются код (префикс номеров заказов), место хранения, из которого берутся остатки и резервируется товар, и коэффициент цены (цена канала = розничная × коэффициент). Система выдаёт ключ API — один раз, в БД хранится только его хеш; при утечке выдайте новый ключ, старый сразу перестанет действовать.

Канал работает с теми же методами `/api/shop/…`, передавая свой ключ в `X-API-Key`. Номер заказа сохраняется как `код:номер` (`ozon:77`), поэтому номера разных площадок не пересекаются; статус канал запрашивает по своему номеру (`GET /api/shop/orders/77`). Заказы всех каналов видны менеджеру интернет-магазина с колонкой «Канал». Адаптер площадки (преобразование её формата в эти методы) остаётся на стороне площадки или промежуточного сервиса.

## «1С:Розница» и кассы

**Чеки продаж и возвратов** — HTTP-сервис или папка обмена.

`POST /api/onec/receipts`:

```json
{"receipts": [{"id": "000123", "datetime": "2026-10-22T12:30:00", "store": "Салон «Центральный»",
               "lines": [{"barcode": "4601234500012", "qty": 11, "price": 160, "discount": 0}]}]}
```

- `store` — название места или его номер; товар — `barcode` или `product_id`;
- `qty < 0` — возврат покупателя;
- повторная загрузка чека с тем же `id` не создаёт дубликат — пропущенный период можно передать заново;
- ответ: `{"created": 1, "skipped": 0, "errors": []}`; ошибочный чек не останавливает остальные.

Папка обмена: файлы `*.json` (тот же формат) или `*.csv` в `data/inbox_1c` загружаются ежечасно и переносятся в `processed`. CSV (разделитель `;`, кодировка UTF-8):

```
чек;дата;точка;штрихкод;количество;цена;скидка
000124;22.10.2026 13:05;Салон «Центральный»;4601234500012;3;160;0
```

Тот же файл можно загрузить вручную: «Продажи → Загрузить чеки «1С»».

**Цены и уценки для касс** — `GET /api/onec/prices[?only_new=true]`: базовые цены товаров и цены уценённых партий (`batch_id`, `discount_pct`, `price`, `valid_until`). С `only_new=true` — только уценки, не выгруженные ранее.

## Поставщики

Заказ при отправке формируется в XLSX и уходит на e-mail поставщика (SMTP); без настроенной почты письмо и файл кладутся в `data/outbox`.

## Погодный сервис

Open-Meteo (без ключа): прогноз температуры и осадков на 14 дней для координат `FLORAPLAN_LATITUDE`/`LONGITUDE`. При недоступности используются климатические средние.
