Первая версия информационной системы «ФлораПлан» — планирование процессов закупки и продажи цветочной продукции по ТЗ практических работ 3–8.

## Что умеет

- **Партионный учёт** со сроком «годен до», расход по FEFO, перемещения, списания с актами, инвентаризация.
- **Приёмка на ТСД**: сканирование упаковок, брак, сокращение срока, фитосанитарный контроль, акт расхождений при отклонении больше 2 %, этикетки партий.
- **Прогноз спроса** по товарам и точкам на 14 дней с квантилями P50/P80/P95: сезонная наивная модель, Хольт–Уинтерс, метод Кростона, праздничные коэффициенты, очистка дней дефицита, поправка на погоду; версии модели публикуются только при WAPE не хуже действующей.
- **Расчёт заказа поставщику** по модели «продавца газет»: Q = max(0, D − S − Z) с учётом сроков годности, кратности, минимальной суммы, бюджета недели (сокращение по ABC, утверждение директором), сценариев праздников.
- **Заказы поставщикам**: согласование, отправка XLSX по e-mail, статусы до приёмки и закрытия.
- **Уценка** партий с истекающим сроком по прогнозу продаж, выгрузка цен в кассы.
- **Интеграция**: чеки «1С:Розница» (HTTP-сервис, папка обмена, CSV/JSON), API интернет-магазина с резервированием и предзаказами, погода Open-Meteo.
- **Отчёты**: продажи и маржа, списания, оборачиваемость, точность прогноза, ABC/XYZ, закупки — с выгрузкой в XLSX.
- 7 ролей, журнал действий, параметры системы, резервные копии, задачи по расписанию.

## Как запустить

- **Windows**: скачайте `FloraPlan-…-windows-x64.zip`, распакуйте, запустите `ФлораПлан.exe` — при первом запуске программа предложит загрузить демо-данные. Вход: `admin`/`admin`, демо-пользователи `director`, `buyer`, `storekeeper`, `florist`, `shop`, `analyst` с паролем `demo`.
- **Сервер (Docker)**: скачайте исходный код релиза, в каталоге `deploy` скопируйте `.env.example` в `.env`, задайте пароли и выполните `docker compose up -d --build`.
