# Руководство пользователя ФлораПлан

ФлораПлан ведёт партионный учёт цветочной продукции со сроками реализации, прогнозирует спрос, рассчитывает рекомендуемые заказы поставщикам, подсказывает уценку и строит отчёты. Ниже — работа по ролям (ТЗ, п. 4.8.8; роли — ПР 3, табл. 3.3).

## Вход

Откройте адрес программы в браузере (по умолчанию `http://127.0.0.1:8000/`), введите логин и пароль. Пароль меняется в меню пользователя (справа вверху) → «Профиль и пароль». Меню слева показывает только разделы, доступные вашей роли.

**Главная** — ключевые показатели: продажи за день и неделю, доля списаний за 30 дней (в % от закупок), точность прогноза (WAPE за 4 недели), партии с истекающим сроком, заказы на согласовании и в пути, онлайн-заказы. Каждый показатель — ссылка на нужный раздел.

## Менеджер по закупкам

**Закупки → Расчёт заказа.**
1. Выберите поставщика. Дата поставки по умолчанию — сегодня + срок поставки; можно выбрать позже.
2. Сценарий праздника подставляется сам, если пиковые дни утверждённого сценария попадают в период; можно выбрать вручную.
3. «Рассчитать» — система покажет по каждому товару:
   - **спрос до следующей поставки** (по графику заказов поставщика) и **D** — квантиль этого спроса с уровнем обслуживания α;
   - **S** — сколько имеющегося запаса успеет продаться до истечения срока;
   - **Z** — заказы в пути;
   - **рекомендацию** $`Q = \max(0,\ D - S - Z)`$, округлённую вверх до кратности упаковки; ссылка «расчёт» раскрывает обоснование.
4. Предупреждения над таблицей: дозаказ до минимальной суммы поставщика, сокращение по бюджету (сначала группа C, потом B), необходимость утверждения директором, использование вчерашнего прогноза.
5. «Создать черновик заказа».

**Карточка заказа.** В черновике можно изменить количества (только кратно упаковке). Если отклонение от рекомендации больше 30 %, укажите причину — без неё заказ не сохранится. Далее:
- «На согласование» — если сумма заказов недели в бюджете, заказ сразу утверждается, иначе уходит директору;
- «Отправить поставщику» — способом из карточки поставщика: XLSX по e-mail (или в папку `data/outbox`, если почта не настроена) либо в API поставщика; если API не ответило, заказ остаётся утверждённым — отправьте его ещё раз;
- «Поставщик подтвердил», «В пути» — по факту; «Закрыть» — после приёмки; «Отменить» — до приёмки.

**График к празднику** — по сценарию: последний день заказа у каждого поставщика и даты заказов по их графику.

**Справочники**: товары (срок реализации, кратность, цена, штрихкод), поставщики (в том числе способ отправки заказа: e-mail или API поставщика с адресом и ключом) и условия поставки (кнопка «Условия»), календарь событий, сценарии праздников (коэффициенты спроса по группам, дата последней поставки; после изменения сценарий нужно утвердить заново).

## Кладовщик

**Приёмка (ТСД)** — интерфейс рассчитан на терминал сбора данных и телефон.
1. Выберите поставку из списка «К приёмке» (заказы в статусе «В пути»).
2. Сканируйте штрихкод упаковки — к позиции добавится одна упаковка. Если поставка пришла точно по заказу — «Всё поступило по заказу».
3. По позициям укажите брак, при необходимости сократите срок реализации (по контролю качества) и опишите качество.
4. Для импортного товара отметьте «Фитосанитарные документы есть» — без отметки позиция не принимается.
5. «Завершить приёмку»: создаются партии с датой «годен до» = дата поступления + срок реализации − сокращение. При отклонении больше 2 %, браке или отсутствии документов оформляется акт расхождений (вкладка «Акты расхождений», выгрузка в XLSX). Кнопка «Этикетки партий» печатает этикетки.

**Запасы и партии**: перемещение со склада в салон (по FEFO — сначала партии с ближайшим сроком), списание выбранных партий с причиной и актом, инвентаризация (фактическое количество по партиям). Клик по номеру партии — история её движений.

## Продавец-флорист

**Сроки и уценка.** Партии вашего салона, у которых до «годен до» осталось не больше 2 дней. Для каждой — сколько продастся по прогнозу и сколько нет, рекомендуемая скидка (10–50 %). Отметьте партии, при необходимости поправьте скидку и нажмите «Уценить выбранные» — новые цены уйдут в кассы. Если товарный вид утрачен — «Списать». Вкладка «Срок истёк» — партии к списанию.

**Продажи** — журнал чеков (чеки касс загружаются из «1С» автоматически), кнопка «Продажа» — продажа, проведённая в системе: товар списывается по FEFO, цена уценённой партии подставляется сама.

**Интернет-заказы** — можно принять заказ по телефону или предзаказ.

## Менеджер интернет-магазина

**Интернет-заказы.** Заказы с сайта приходят автоматически и сразу резервируют товар, годный на дату доставки. Если товара не хватает — заказ становится предзаказом. Когда товар поступит на место интернет-магазина (приёмка или перемещение), предзаказ резервируется сам — первыми те, что доставлять раньше; кнопка «Резерв» нужна, если товар появился иначе (например, после инвентаризации). «Выполнен» — резерв превращается в продажу; «Отменить» — резерв снимается. Колонка «Канал» показывает, откуда пришёл заказ: основной сайт или подключённый маркетплейс. Телефон покупателя видят только менеджер интернет-магазина и администратор; через год (параметр «Обезличивать данные покупателей…») в выполненных и отменённых заказах имя, телефон и комментарий стираются автоматически (152-ФЗ).

## Аналитик

**Прогноз спроса.**
- «График» — факт продаж и прогноз P50 (медиана), P80 и интервал до P95 по товару и точке.
- «Прогноз по товарам» — суммы на 7 и 14 дней, выбранная модель.
- «Версии модели» — пересчёт параметров: выберите алгоритм (автовыбор, сезонная наивная, Хольт–Уинтерс, Кростон), отложенный период, тренд, учёт погоды и нажмите «Оценить новую версию». Система сравнит недельный WAPE по товарным группам с действующей версией на том же периоде. «Опубликовать» — только если новая версия не хуже.
- «Рассчитать сейчас» — внеочередной расчёт (обычно — ежедневно в 03:00).

**Отчёты**: продажи и маржа, списания (доля от закупок), оборачиваемость, точность прогноза (критерий проекта — WAPE ≤ 25 %), ABC/XYZ, закупки. Любой отчёт выгружается в XLSX.

**Администрирование → Обмен и расписание** — журнал обмена с «1С», сайтом и погодным сервисом, время следующего запуска задач, загрузка чеков из папки обмена по кнопке.

## Директор

Утверждает заказы сверх бюджета (Закупки → карточка заказа → «Утвердить» или «Вернуть на доработку» с комментарием), утверждает сценарии праздников, смотрит отчёты, журнал действий и задаёт параметры (бюджет недели, пороги уценки, расхождений, причины изменения заказа и др.) в «Администрирование → Параметры».

## Администратор

- **Пользователи** — учётные записи и роли, блокировка, смена пароля.
- **Каналы продаж** — подключение маркетплейса или другого сайта: название, код (префикс номеров заказов), место хранения для остатков и резерва, коэффициент цены. После сохранения система один раз показывает ключ API — передайте его площадке. «Новый ключ API» отменяет старый; отключённый канал перестаёт получать остатки и передавать заказы.
- **Резервные копии** — создать копию сейчас и скачать любую из 14 последних. Восстановление — командой `floraplan restore` (см. руководство администратора).
