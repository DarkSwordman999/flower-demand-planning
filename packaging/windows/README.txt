ФлораПлан — планирование закупок и продаж цветочной продукции
=============================================================

Запуск (установка не нужна)
---------------------------
1. Распакуйте архив в любую папку, например C:\FloraPlan.
2. Запустите ФлораПлан.exe.
3. При первом запуске программа предложит загрузить демонстрационные данные — нажмите Enter
   (около 1–2 минут). Затем в браузере откроется http://127.0.0.1:8000/.
4. Не закрывайте чёрное окно, пока работаете: это сервер программы.

Вход
----
Администратор: admin / admin  (смените пароль: меню пользователя → «Профиль и пароль»).
Демо-пользователи, пароль demo:
  director    — директор
  buyer       — менеджер по закупкам
  storekeeper — кладовщик (приёмка на ТСД)
  florist     — продавец-флорист
  shop        — менеджер интернет-магазина
  analyst     — аналитик

Данные
------
Все данные лежат в папке data рядом с программой:
  data\floraplan.db  — база данных;
  data\backup        — резервные копии (ежедневно в 02:00, хранятся 14 последних);
  data\outbox        — заказы поставщикам (XLSX), если не настроена почта;
  data\inbox_1c      — папка обмена: чеки «1С» (JSON или CSV) загружаются ежечасно.
  data\secret.key    — ключ подписи входа в систему, создаётся при первом запуске; не передавайте
                       его посторонним (с ним можно войти под любым пользователем).
Для переноса на другой компьютер скопируйте папку целиком.

Команды
-------
  ФлораПлан.exe demo --reset   — заново загрузить демо-данные (все данные будут удалены!)
  ФлораПлан.exe backup         — резервная копия базы
  ФлораПлан.exe restore <копия> — восстановить базу из копии (папка data\backup); программу закройте
  ФлораПлан.exe create-user ivanova пароль buyer --name "Иванова А. А."

Настройки (переменные окружения или файл .env рядом с программой)
------------------------------------------------------------------
  FLORAPLAN_PORT=8000                 порт веб-интерфейса
  FLORAPLAN_HOST=0.0.0.0              доступ с других компьютеров сети и ТСД
  FLORAPLAN_SSL_CERTFILE=cert.pem     HTTPS: сертификат и закрытый ключ в формате PEM
  FLORAPLAN_SSL_KEYFILE=key.pem
  FLORAPLAN_DATABASE_URL=postgresql+psycopg://user:pass@host:5432/flora_db   работа с PostgreSQL
  FLORAPLAN_SMTP_HOST, _PORT, _USER, _PASSWORD, _FROM   почта для заказов поставщикам
  FLORAPLAN_SHOP_API_KEY, FLORAPLAN_ONEC_API_KEY        ключи интернет-магазина и «1С»

Описание API: http://127.0.0.1:8000/api/docs
